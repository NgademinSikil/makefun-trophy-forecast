Forecasts, for each of Grand Theft Auto VI's 55 PlayStation 5 trophies, five quantiles (5%, 25%, 50%, 75%, 95%) of its Exophase earn rate at the case's target, from the house's recorded reads up to the checkpoint. Python 3.13, standard library only, no network, deterministic.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
